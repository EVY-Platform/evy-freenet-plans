# AGENTS instructions for freenet-plans

Please remove all mannered prose and write to the user in plain language: follow ISO 24495 and the rules below.

Avoid keeping historic or negated old text: "Old approach was x", "We won't do x", "We can't do x". We only ever want to mention things that we WILL be doing.

Use mermaid, flow charts, tables and bullet points where possible to make the content easier to read.
